## Individual Responsibilities

### 1. Team Leader & Core Search Engine Developer

- System architecture design.
- TF-IDF vectorization.
- Document and query representation.
- Cosine similarity computation.
- Document ranking and Top-K retrieval.
- Main application development.
- System integration and repository management.
- Technical supervision and code review.

### 2. Dataset Engineering & Data Cleaning

- Dataset acquisition and source documentation.
- Reproducible dataset sampling.
- Duplicate detection and removal.
- Missing and empty text handling.
- Document ID and metadata management.
- Structured CSV dataset preparation.
- Dataset validation.

### 3. NLP & Text Preprocessing Developer

- Text normalization and lowercasing.
- Tokenization.
- Configurable stopword removal.
- Stemming or lemmatization.
- Consistent document and query preprocessing.
- Before-and-after preprocessing demonstrations.
- Preprocessing validation.

### 4. Inverted Index Developer

- Inverted index construction.
- Python dictionaries and sets implementation.
- Posting lists generation.
- Term-to-document mapping.
- Document metadata retrieval.
- Index validation and testing.

### 5. Boolean Retrieval Developer

- Boolean search engine implementation.
- AND, OR, and NOT operations.
- Boolean query parsing.
- Exact-match document retrieval.
- Empty and invalid query handling.
- Boolean search validation and testing.

## Shared Responsibilities

All team members are responsible for:

- Implementing and testing their assigned components.
- Maintaining individual GitHub commits.
- Documenting technical decisions and progress.
- Participating in code reviews and system integration.
- Recording reproducible test results.
- Participating in the final project presentation.
- Citing external code, datasets, and AI assistance.

## Development Status

The responsibilities listed above represent the planned task allocation. Actual individual contributions will be documented throughout project development.
