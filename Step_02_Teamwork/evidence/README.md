# Development and Teamwork Evidence

## 1. Overview

This directory contains supporting evidence for the development, teamwork, testing, and integration activities of the Medical Research Search project.

The evidence supports the Phase 1 assessment criterion for Progress and Teamwork (3 marks).

## 2. Evidence Objectives

- Demonstrate incremental project development.
- Verify individual technical contributions.
- Document GitHub commits and pull requests.
- Demonstrate actual module functionality.
- Record reproducible testing results.
- Provide evidence of successful system integration.
- Support transparent academic assessment.

## 6. Dataset Evidence Requirements

The dataset evidence should include:

- Dataset source.
- Dataset revision.
- Number of original records examined.
- Number of duplicate records removed.
- Number of invalid or empty records removed.
- Final document count.
- Sampling configuration.
- Dataset validation results.
- Actual execution command.

## 7. Preprocessing Evidence Requirements

The preprocessing evidence should demonstrate:

- Original document text.
- Text after lowercasing.
- Tokenization results.
- Stopword handling.
- Stemming or lemmatization results.
- Final processed terms.

At least one complete preprocessing example must be provided.

## 8. Inverted Index Evidence Requirements

The inverted index evidence should include:

- Number of indexed documents.
- Number of unique indexed terms.
- Actual posting list examples.
- Term-to-document ID mappings.
- Index validation results.

## 9. Boolean Search Evidence Requirements

The Boolean search evidence should demonstrate:

- At least one AND query.
- At least one OR query.
- At least one NOT query.
- Actual matching document IDs.
- Matching document titles.
- Number of matching documents.
- Empty and invalid query handling.

## 10. Ranked Search Evidence Requirements

The ranked search evidence should demonstrate:

- TF-IDF document matrix information.
- Query vector transformation.
- Cosine similarity computation.
- At least three ranked search queries.
- Document IDs and titles.
- Actual similarity scores.
- Descending Top-K results.
- Explanation of the highest-ranked document for each demonstration.

## 11. System Integration Evidence Requirements

The integration evidence should include:

- Successful execution of the main application.
- Dataset loading results.
- Integrated preprocessing pipeline.
- Boolean search execution.
- Ranked search execution.
- Console interface demonstration.
- Integration test results.
- Reproducible execution commands.

## 13. Evidence Verification Policy

All recorded evidence must originate from actual development or system execution.

Illustrative examples, simulated outputs, and synthetic test fixtures must be clearly identified.

Individual contributions must be attributed to their actual contributors.

Screenshots may be used as supplementary evidence, while textual execution logs and commit links are preferred for reproducibility.

External code, datasets, libraries, and relevant AI assistance must be appropriately acknowledged.
