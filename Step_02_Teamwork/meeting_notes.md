## 4. Initial Planning and Coordination

**Date:** November 16, 2026

**Coordinator:** Team Leader

**Type:** Project planning and task organization

### Project Decisions

- Select Medical Research Search as the project topic.
- Use the TREC-COVID dataset provided through BEIR.
- Target a collection of 1,000 valid biomedical research documents.
- Use Python as the primary programming language.
- Implement Boolean and ranked information retrieval.
- Use a shared text preprocessing pipeline.
- Construct the inverted index using Python dictionaries and sets.
- Implement AND, OR, and NOT operations.
- Use TF-IDF and cosine similarity for ranked retrieval.
- Provide a Python console interface.
- Organize development using individual GitHub branches.
- Use pull requests and code reviews for integration.
- Target complete project readiness by November 17, 2026.
